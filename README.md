# Real-Time Sentiment Analysis on Twitter Data Using NLP

## 📌 Project Overview

This project performs sentiment analysis on Twitter data using Natural Language Processing (NLP) techniques. The system analyzes tweets and classifies them into **Positive, Negative, and Neutral** sentiments to understand public opinion and social media trends.

The project demonstrates text preprocessing, sentiment classification, and visualization of social media data.

---

## 🎯 Objective

- Analyze Twitter data and identify user sentiment.
- Clean and preprocess tweet text using NLP techniques.
- Classify tweets into Positive, Negative, and Neutral categories.
- Visualize sentiment patterns and frequently used words.
- Understand public opinion from social media data.

---

## 📂 Dataset

The project uses a Twitter sentiment dataset containing:

- Tweet ID
- Entity/Topic
- Sentiment Label
- Tweet Content

The dataset contains tweets related to different topics and their corresponding sentiment categories.

## 🧹 Data Preprocessing

The following NLP preprocessing steps were performed:

- Converted text into lowercase
- Removed URLs
- Removed mentions (@users)
- Removed hashtags symbols
- Removed punctuation
- Removed stopwords

---

## 🤖 Sentiment Analysis

VADER (Valence Aware Dictionary and sEntiment Reasoner) was used for sentiment analysis.

Tweets are categorized into:

- 🟢 Positive
- 🔴 Negative
- ⚪ Neutral

---

## 📊 Visualizations

The project includes:

### Sentiment Distribution

Shows the number of tweets belonging to each sentiment category.

### Sentiment Percentage

Displays the percentage contribution of each sentiment.

### Entity Analysis

Shows the most discussed topics/entities.

### Word Cloud

Displays the most frequently used words in tweets.
